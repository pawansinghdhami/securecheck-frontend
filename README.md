# SecureCheck Frontend

SecureCheck Frontend is the user-facing dashboard for the SecureCheck cybersecurity platform. It helps users authenticate, run domain scans, review security findings, monitor scan history, and compare report trends in a clean and modern interface.

## What it does

- User signup and login experience
- Dashboard for monitoring website security posture
- Domain scanning workflow from the frontend
- Security score and audit summary views
- Historical scanning and detailed findings pages
- Comparison view to track improvements over time

## Features

- Responsive Next.js dashboard UI
- Authentication flow for users
- Risk overview and findings presentation
- Scan history and result detail pages
- Comparison charts for previous audits
- Clean, mobile-friendly layout built with Tailwind CSS

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Recharts

## Getting started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the app in your browser at:

```text
http://localhost:3000
```

## Project goal

The frontend makes security assessment simple and understandable for both technical teams and decision-makers by presenting results in a visual, actionable dashboard.
